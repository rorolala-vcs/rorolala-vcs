# ask-contributing

## Introduction

Lists the `# Contributing` section of every README under `app/`, `modules/`, `utils/`, `dev/`,
`tests/` and `book/`, so an agent can answer what can be contributed and what a contributor's
machine needs without opening each README.

## Boundary

It reads README headings and prints what they say. It does not judge whether the text is accurate,
run a build or the gate, or write any file.
