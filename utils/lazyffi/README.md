# rorolala-utils-lazyffi

FFI export for Rorolala: the `#[lazyffi]` attribute, the conversions between Rust
types and their repr-C siblings, and the runtime helpers the generated code calls.

It exports structs, unit-only enums, data-carrying enums (as a tag plus a payload
union), constants, free functions, and inherent `impl` blocks. The C header for
everything it exports is generated by `rorolala-dev-bindgen`.

The procedural macros live in `rorolala-utils-lazyffi-macros` and are re-exported from this
crate's root, so depend on this crate only. The naming and shape rules shared with the
header generator live in `rorolala-utils-lazyffi-core`.
