# rorolala-ffi

The C ABI surface of Rorolala: a `cdylib`/`staticlib` built on `rorolala-utils-lazyffi`.

Items annotated with `#[lazyffi]` are exported with `#[unsafe(no_mangle)]`; this crate
re-exports the libraries that declare them, so the symbols end up in the produced
`librorolala_ffi.so` / `.a`.

## Generated bindings

The C header is generated by the **root** build script through
`rorolala-dev-bindgen`, into `{target_dir}/{profile}/ffi_bindings/`:

```
.cargo/temp/debug/ffi_bindings/rorolala_ffi.h
.cargo/temp/release/ffi_bindings/rorolala_ffi.h
```

Debug and release are kept apart. Unlike cbindgen, the self-built generator resolves
the associated types `#[lazyffi]` puts in its signatures, and needs neither macro
expansion nor a nightly toolchain.
